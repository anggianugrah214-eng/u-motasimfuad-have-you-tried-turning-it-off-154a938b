A program entry for make.fun's **"Have You Tried Turning It Off?"** bounty ($10 in USDC).

## What it does

`main.py` writes one funny line a hopeless tech support agent says to a desperate customer to `/output/entry.txt`:

> Have you tried turning it off and on again? It's step one of two — step two is turning it off and on again.

The agent opens with the classic line, then reveals the entire troubleshooting guide is that one step repeated — cheerful uselessness as the whole joke, and the customer is never the butt of it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is fully deterministic: the same 107-character line is written on every run. It takes no input, makes no network calls, and needs no dependencies beyond Python 3.

## The line

Fourteen candidates were drafted and scored against the published judge brief (see `candidates.md` in the build workspace). The winner twists the competition's namesake classic — exactly what the brief's fifth criterion rewards — while sounding like a real support agent reading from a script.
